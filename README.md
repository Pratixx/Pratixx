# About Me

Just a boring guy making things I love. I spend a lot of time on commenting my code so if anything here is interesting to you
my code may be a useful resource. I don't very actively use GitHub so if my commits are months apart then don't be surprised.

I really am not a fan of abstraction. I like to have as few dependencies as possible, and I like when I understand what is going on
under the hood. It's the primary reason I am highly against web development, using third-party libraries, or using any language other
than C and Assembly. If you see me ever using Java, C++, Rust, Go, Zig, Python, or any other such language, it most likely has a very,
very specific use case.
